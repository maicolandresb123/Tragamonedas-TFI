# Tragamonedas TFI

Proyecto de Introducción a la Programación con Python y ampliación gráfica.

- `referencia/Tragamonedas corregido.py`: archivo de consola con los 15 TODO y los bonus oficiales, sin cambios para la web.
- `docs/`: interfaz web estática compatible con GitHub Pages.

## GitHub Pages

Configurar **Settings → Pages → Deploy from a branch → main /docs**.

**Nota:** GitHub Pages ejecuta HTML, CSS y JavaScript, pero no Python. La versión web reproduce las reglas del ejercicio y guarda saldo e historial mediante almacenamiento local del navegador; no escribe archivos `.txt` automáticamente. Para descargar historial, usar el botón de la página. El programa Python académico continúa funcionando por consola de forma independiente.
